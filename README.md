# homework

中文数学练习试卷生成脚本。每个脚本生成一类题目，支持通过 `--copies` 一次生成多份并写入同一个可打印的 A4 PDF。所有题目页在前，各份答案独占一页、按份号顺序集中在文件末尾；多份输出时页脚标明份号，各份题号从 1 开始。

## 安装

需要 Python 3.10 或更高版本。

```bash
python -m pip install -r requirements.txt
```

## 脚本列表

| 脚本 | 生成内容 |
| --- | --- |
| `multiplication_grade4.py` | 四年级上册多位数乘两位数乘法练习：10 道三位数乘两位数口算；10 道竖式计算，其中 5 道三位数乘两位数、5 道四位数乘两位数。全卷题目不重复。口算两个因数均以零结尾；竖式题不限制末尾是否为零，给横式并留出列竖式空间。题目一页，乘积答案一页。 |

### 多位数乘两位数

无必填参数；默认每次随机生成试卷。

```bash
python multiplication_grade4.py
```

| 参数 | 用途 | 必填 | 默认值 |
| --- | --- | --- | --- |
| `--output` | 输出 PDF 路径，必须以 `.pdf` 结尾；自动创建父目录，同路径文件会被覆盖 | 否 | `output/multiplication_grade4.pdf` |
| `--seed` | 整数随机种子，相同种子生成相同题目 | 否 | 不固定，每次随机 |
| `--copies` | 一次生成的份数，仅接受正整数；每份重新随机出题，同一份内题目不重复，份与份之间允许重复；相同种子和份数复现整批题目 | 否 | `1` |

指定输出位置和随机种子：

```bash
python multiplication_grade4.py --output output/example.pdf --seed 42
```

一次生成 3 份题目及对应答案，写入同一个 PDF（前 3 页为题目，后 3 页为对应答案）：

```bash
python multiplication_grade4.py --copies 3 --output output/batch.pdf --seed 42
```

中文字体随 PDF 内嵌，无需另外安装字体。

教材依据：已核对用户提供的《数学 四年级上册》PDF（人民教育出版社，封面带有“2024”教材审核标识）第三单元“多位数乘两位数”。以下均为教材印刷页码，PDF 阅读器页码需加 3：

- 第 40 页有 `120×30` 等口算练习；第 48 页有 `160×60` 及因数中间、末尾有零的乘法练习。
- 第 43—44 页讲解乘两位数的竖式计算；第 51 页列有 `3700×35`、`3070×35`，确认包含四位数乘两位数练习。

本脚本按用户确认的要求编排：口算全部为三位数乘两位数，两个因数均以零结尾；竖式计算各含 5 道三位数和 5 道四位数乘两位数。题目页从题型分节开始，不显示主标题、副标题及姓名、班级、日期栏；答案页保留标题。
